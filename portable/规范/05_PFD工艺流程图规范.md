# 05 PFD 工艺流程图规范

版本：V1.0｜2026-10-19。主要教学来源S04第16—20张；以下组织规则为【项目约定】。

## 1. PFD应回答的问题

PFD表达工艺路线、主要设备、主要物流、关键操作条件和物料/能量联系。应让读者沿原料到产品、循环、排放及副产品的路径理解生产过程。

PFD不是按场地坐标绘制的设备布置图，也不承担详细阀门、全部仪表和管件的表达任务。哪些控制信息出现在PFD，应由项目深度规定，不为图面好看随意增删。

## 2. 绘图输入

- 已确定的路线和操作方式。
- 物料、能量衡算和经核查的模拟结果。
- 设备初步表及位号规则。
- 物流号、组成基准、温压及流量单位。
- 公用工程边界、排放及循环去向。

未完成衡算时可以画流程草图，但必须明确为讨论稿，不能把空白物流表当成完成的PFD。

## 3. 图面组织

1. 主流程优先从左向右，相关单元分组，减少长距离回绕。
2. 关键高低关系可示意表达，但不让示意高度冒充真实安装标高。
3. 主物流、辅助介质和能量流以图例区分；进出界区清楚标识。
4. 箭头靠近分支、入口、出口等易混淆位置；双向流要说明工况。
5. 回流、循环、旁路、放空及废物流都必须有明确起止，不允许管线悬空。
6. 拆图后使用成对跨图接续标识，能定位到具体图号和连接编号。

## 4. 设备表达与位号

设备符号选用项目确认的图例，保留设备型式的关键差异，例如塔器、釜式反应器、换热器和容器。并联、串联及备用关系必须与设备表一致。

位号示例可采用`T-0101`、`E-0101`、`V-0101`、`P-0101A/B`，但字母含义、分隔符和数字分段均须在首页说明；该示例不是所有单位的统一标准编码。

标注设备位号、名称和必要工艺参数。设备操作压力、操作温度与设计参数分栏，不把不同含义的数据写在同一个无标题文本框中。

## 5. 物流编号和数据表

物流编号必须唯一，图中、模拟中和物流表中能相互映射。软件节点名可保留，但不依赖软件默认名称作为唯一设计解释。

|字段|要求|
|---|---|
|物流号|与图中标记相同|
|来源、去向|设备位号或界区接口|
|总流量|明确质量/摩尔/体积基准与时间单位|
|组成|明确质量分数、摩尔分数或其他基准，列主要杂质|
|温度|明确单位|
|压力|注明表压或绝压，不能只写MPa|
|相态|需要时给出气液比例及其基准|
|焓或能量信息|需要时注明参考态与单位|
|工况|正常、最大、最小或特殊工况|

标准状态体积流量必须明确参考温度和压力，不只写`Nm³/h`就认为定义完整。不同物性包的焓值不能在未统一参考基准时直接混算。

## 6. 物料和能量的闭合

- 为全流程、反应段、分离段和回收循环分别定义检查边界。
- 总质量、关键组分/元素与能量检查分开记录，明确反应、累积、损失和放空。
- 反应前后总摩尔数可能变化，不能机械要求摩尔流量总和相等。
- 稳态、非稳态和批次计算使用各自的积累项与时间基准。
- 闭合容差由项目规定，报告绝对差和相对差，不能只写“基本平衡”。

## 7. 公用工程和副产物流

工艺需要的蒸汽、冷却、冷冻、加热、氮气及其他介质，应按阶段深度标明。冷凝液、排污、废气、废水、副产品及未反应物的最终去向必须能够追踪。

循环系统检查物料积累与排放路径；不能仅以“提高收率”为由让惰性或杂质无限循环。

## 8. 与其他文件的接口

|对应文件|必须一致的内容|
|---|---|
|设计说明书|路线、规模、运行方式和物料边界|
|模拟文件|设备功能、主要物流、计算工况|
|设备表|位号、名称、数量和主要型式|
|P&ID|工艺连接与设备功能；细节允许按阶段深化但需受控|
|公用工程负荷表|负荷、介质等级、消耗和回收|
|总图及设备布置|装置和设备的实际存在及重要工艺联系|

## 9. PFD检查清单

- [ ] 每条主物流可以从来源追踪至最终去向。
- [ ] 物流号与物流表一一对应，遗漏、重复有解释。
- [ ] 原料、产品、副产品、排放和循环均已表示。
- [ ] 温压、流量、组成基准和工况清楚。
- [ ] 反应器、分离和换热功能与说明书一致。
- [ ] 衡算误差有独立检查记录。
- [ ] 所用设备图例和符号在首页可查。
- [ ] 图名、图号、修订和跨图连接闭合。
