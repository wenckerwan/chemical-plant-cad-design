# CAD 化工设计与绘图规范

版本：V1.0｜编写日期：2026-10-19｜适用阶段：课程设计、毕业设计、方案设计和设计文件准备。

这是一套根据本地化工设计与制图资料整理的工作规范，规定如何收集条件、组织设计、绘制图纸、校核和交付。它不是国家或行业标准的替代文本，也不是某个具体工厂已经通过审核的设计文件。

## 1. 先确定规则的性质

全文采用以下标识：

|标识|含义|使用方法|
|---|---|---|
|【标准要求】|已取得适用标准原文、已核对版本和具体条款的要求|必须在项目依据表中填入标准、条款、适用条件和核验记录；本手册不会用此标识冒充尚未核验的数值|
|【课程资料】|本地讲义、课件或历史竞赛资料中的方法与要求|用于学习与课程绘图，是否作为交付依据由本次任务书确定|
|【项目约定】|本目录建议采用的统一管理或绘图规则|项目未另行规定时采用；修改时全套图纸同步修改|
|【待核验】|资料不足、版本未核定或需要专业计算的条件|可以在草稿中保留，正式发布前必须落实或有明确的阶段排除说明|

本目录中没有另行注明来源的流程、表单、文件命名和检查要求，均为【项目约定】。使用“必须”“不得”时，其约束范围是本项目的内部工作质量要求，并不因此变成国家强制条文。

## 3. 推荐阅读路径

- 只画厂区图：01 → 02 → 03 → 04 → 11 → 12。
- 画设备布置图：01 → 02 → 03 → 07，并对照 05、06。
- 画 PFD/P&ID：01 → 03 → 05 → 06 → 10 → 11。
- 画管道图：06 → 07 → 08 → 09，并落实 10 中的工况和管线数据。
- 做完整课程设计：按 01 至 13 阅读，建立本项目设计基础和图纸目录。

## 4. 必须避免的十类错误

1. 把厂区总图、设备布置、PFD、P&ID画成同一种图。
2. 从别人的图中复制一个安全距离，未核对设施类别、容量和测量起点。
3. 把“全年最小频率风向”当成“全年主导风向”。
4. 以设备外形不碰撞代替操作、检修、吊装和疏散空间检查。
5. P&ID、设备表和布置图中的设备数量、位号或立卧型式不一致。
6. 只改显示尺寸或使用尺寸覆盖文字，实际几何没有修改。
7. 不区分m与mm、表压与绝压、正常工况与设计工况。
8. 用操作压力直接代替设计压力，或用模拟软件收敛代替工程校核。
9. 把 STEP/STL、截图或PDF称为已经交付可编辑DWG。
10. 将草稿、自动生成文件或未经校核的结果标成施工图、批准图。

## 5. 跨电脑使用原则

- 本规范包是纯Markdown参考，不依赖原作者的盘符、用户名、AutoCAD安装目录或缓存。
- 原始PDF、PPT、DWG、字体、商业软件、CAD插件与运行时未随包分发；不在新电脑上假定这些内容存在。
- 阅读规范和形成设计条件不需要CAD软件；实际生成、修改、打开和打印图纸需要在目标电脑检查相应工具。
- 原始资料名称与阅读页码保留在13号来源文档中，属于历史来源记录，不是必须能访问的本地路径。
- 标准核验记录的日期不随迁移刷新；当前项目仍需确认适用版本与条款。
- 本包在开发机完成的检查不能当成新电脑的兼容性结论，按[能力检查与迁移](14_工具能力与迁移.md)进行实际验证。

## 6. 每个新项目的第一步

复制12号文档中的项目基础表，写明交付图种、设计阶段、产品规模、厂区边界、坐标单位、标准版本、图幅、DWG版本、数据缺项和责任人。未确定的参数不填成0，也不根据“常见值”偷偷补齐。
