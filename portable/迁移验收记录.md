## 2. 安装器功能验收

在开发机Windows及实际可用Python运行时执行了9项标准库测试：

1. 改名、中文和空格路径下的安装预览不创建目标目录。
2. 完整安装参考文件，重复安装相同内容返回`unchanged`。
3. 已安装内容被修改时拒绝覆盖，保留用户内容。
4. 包文件内容校验失败时在写入前拒绝。
5. 兼容模式使用当前环境的CODEX_HOME定位，不沿用开发机路径。
6. 拒绝安装到源发行包内部造成递归复制。
7. 拒绝manifest中的路径穿越。
8. 拒绝未列入清单的载荷文件。
9. 拒绝skill内损坏的相对参考链接。

标准skill校验器已验证SKILL.md名称、frontmatter和脚手架占位问题。完整发行包仍通过`install.py --verify-only`检查载荷与引用；独立规范与skill参考逐文件同步。

安装器不需要PyYAML；开发机运行官方skill校验器时使用的PyYAML仅为开发验证依赖，不随包成为目标电脑安装前提。

- [ ] 读取两条应用示例，确认按项目约定和资料来源答复。
- [ ] 对实际CAD工具完成最小图形、字体、尺寸和打印测试。
- [ ] 核对所需DWG版本、图块、外参和字体。
- [ ] 对当前工程重新确定适用标准和项目设计输入。

没有在另一台真实Linux/macOS电脑进行CAD实机测试，不把当前验证扩大为跨平台CAD兼容认证。

## 4. 重新运行安装器测试

在发行包根目录使用Python 3.9或更高版本：

```bash
python tests/test_install.py
```

测试只使用临时目录，不会安装到真实技能目录，也不会联网。不要使用编译/编辑工具修改发行包后仍期待原manifest校验通过；自定义维护应生成新的发布清单。
